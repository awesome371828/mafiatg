# Mafia Keep

Telegram-бот для классической «Мафии» в группах на Python 3.11+ и aiogram 3.x.

## Возможности

- Групповое лобби с кнопками регистрации и выхода.
- Роли: мафия, дон, шериф, доктор, путана и мирный житель (набор зависит от числа участников).
- Ночь с действиями ролей в личных сообщениях, день с голосованием в группе.
- Проверка условий победы и сохранение профилей/статистики.
- Админ-команды владельца Telegram ID `6652898792`: `/ban_player ID [причина]`, `/unban_player ID`, `/game_status`, `/stat`.
- Данные игроков и блокировок хранятся в `data.json`.

## Быстрый запуск

1. Создайте Telegram-бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. В репозитории GitHub откройте **Settings → Secrets and variables → Actions → New repository secret**.
3. Имя секрета: `TELEGRAM_TOKEN`. Значение — токен бота. Не помещайте токен в код и не публикуйте его.
4. Откройте вкладку **Actions**, выберите **Mafia Keep Bot** и нажмите **Run workflow**.
5. Откройте личный чат с ботом и нажмите **Start**. Добавьте бота в группу через кнопку приветствия.
6. В группе выполните `/new_game`. Участники нажимают «Записаться». Когда соберётся минимум четыре игрока, выполните `/start_game`.
7. Все игроки должны хотя бы один раз открыть личный чат с ботом и нажать **Start**, иначе бот не сможет отправлять им роли и ночные действия.

## Команды

- `/start` — приветствие и ссылка добавления в группу.
- `/new_game` — создать лобби в группе.
- `/start_game` — начать игру (минимум 4 игрока).
- `/profile` — профиль, победы и поражения.
- `/ban_player ID [причина]` — блокировка игрока (только владелец).
- `/unban_player ID` — снять блокировку (только владелец).
- `/game_status` — посмотреть активные игры в личке владельца или сбросить игру в группе.
- `/stat` — статистика бота (только владелец).

## Бесплатный запуск через GitHub Actions

Workflow `.github/workflows/mafia_server.yml` запускается вручную и по расписанию. Он запускает процесс до 18 000 секунд (5 часов), после чего Python сохраняет данные и корректно завершает polling. Workflow затем коммитит изменённый `data.json`.

В **Settings → Actions → General → Workflow permissions** выберите **Read and write permissions**. В workflow также выставлено `permissions: contents: write`.

GitHub Actions не является VPS и не гарантирует непрерывность 24/7: расписание может задерживаться, запуск может быть остановлен лимитами GitHub, а бесплатные минуты ограничены условиями аккаунта. Здесь намеренно нет бесконечной самоперезапускающейся цепочки через API: GitHub ограничивает рекурсивные запуски событий, а бесконечный цикл не превращает Actions в гарантированный хостинг. По расписанию запускается новый контейнер; если нужно гарантированное постоянное соединение, используйте постоянно работающий хостинг.

## Важные ограничения

- Активное состояние текущей партии хранится в памяти и сбрасывается при перезапуске; постоянными являются профили, статистика и баны в `data.json`.
- Поскольку файл содержит ID/имена пользователей и историю блокировок, публичный репозиторий означает публичность этих данных. Для реального сообщества предпочтительнее сделать репозиторий приватным или перенести данные в БД.
- Для группового голосования и личных ночных действий участники должны нажать Start в личном чате бота.
