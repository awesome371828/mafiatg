# Mafia Keep

Минималистичный Telegram-бот для групповой «Мафии» на Python 3.11+ и aiogram 3.x.

## Игра

- В группе отправьте `/game`, `/new_game` или `/mafia`. Также распознаются фразы «старт мафия», «начать мафию», «го в мафию» и похожие варианты.
- Участники нажимают «🎭 Записаться». Бот обновляет список прямо в том же сообщении.
- По умолчанию включён тестовый режим на 2 игрока. Для обычных партий владелец может поставить минимум 4+ в `/admin → Настройки игры`.
- «▶ Начать» раздаёт роли в личные сообщения. Каждый игрок должен заранее нажать `/start` в личке бота.
- Ночь и день идут по таймеру; голосование и ночные действия выполняются кнопками.
- Партия завершается автоматически при победе стороны; после окончания бот показывает роли.
- Роли: Мирный, Мафия, Дон, Комиссар, Сержант, Доктор, Маньяк, Любовница, Адвокат, Самоубийца, Бомж, Счастливчик, Камикадзе, Журналист, Телохранитель и Мэр. Некоторые специальные роли включаются только для подходящего количества игроков.

## Команды

- `/start` — короткое меню и кнопка добавления в группу.
- `/game`, `/new_game`, `/mafia` — открыть регистрацию в группе.
- `/start_game` — запустить партию вручную.
- `/cancel_game` — отменить свою игру.
- `/profile` — статистика игрока (команда, кнопки профиля в меню нет).
- `/leaderboard` — топ игроков по победам.
- `/admin` — панель владельца, только Telegram ID `6652898792`.
- `/set_min_players N` — установить минимум игроков.
- `/stat` — статистика бота.
- `/game_status` — в личке показывает активные игры; в группе сбрасывает игру.
- `/ban_player ID [причина]`, `/unban_player ID` — управление блокировками.
- `/broadcast текст` — рассылка пользователям, открывавшим бота.

## Панель владельца

В `/admin` доступны статистика, активные игры, настройки минимального/максимального числа игроков, длительности ночи/дня/регистрации, тестовый режим на двух игроков, показ ролей после смерти, включение/выключение специальных ролей, сброс игр, блокировки и рассылка.

Настройки хранятся в `data.json`. Не удаляйте файл, если хотите сохранить данные.

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather).
2. В GitHub откройте **Settings → Secrets and variables → Actions** и создайте секрет `TELEGRAM_TOKEN`.
3. Откройте **Actions → Mafia Keep Bot → Run workflow**.
4. Убедитесь, что бот отвечает на `/start`, затем добавьте его в группу.

GitHub Actions запускает процесс ограниченное время и не гарантирует непрерывность 24/7. При перезапуске активные партии сбрасываются; статистика, блокировки и настройки сохраняются в `data.json`.

Поскольку `data.json` содержит Telegram ID и имена игроков, для реального сообщества рекомендуется сделать репозиторий приватным или перенести данные в базу данных.
